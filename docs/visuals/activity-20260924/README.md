# Native Activity UI fixtures

These images are generated by `GoalongAnalyticsRenderingTests` using only the
fixed synthetic developer-preview fixture. They contain no user activity,
private browsing, real projects, account information or desktop screenshots.
Installed native application artwork is used to exercise the same icon resolver
as the live interface. The compact image is rendered at 640 points and the wide
image at 1000 points, in light and dark appearances respectively.

Generate with the opt-in `GOALONG_ANALYTICS_SNAPSHOTS` test environment variable.
Dates and activity durations in these images are examples, not a real history.
